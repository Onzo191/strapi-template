02

Chi tiết hạng mục phải xây dựng theo Phase

Mỗi phase gom theo workstream. Dòng in nhạt là tiêu chí nghiệm thu (acceptance) cần đạt.

P0

Nền tảng & Bàn giao — Centralize về IT

15 – 30/06/2026

HandoverTiếp nhận source & hạ tầng

  • Nhận source code website từ VNGGames, IR page từ A4B Kèm tài liệu kiến trúc, credential, quyền repo/hosting
  • Centralize hosting về đầu mối IT Đang làm
  • Kiểm kê stack hiện tại, vẽ lại kiến trúc hệ thống

DevOpsMôi trường & CI/CD

  • Dựng 3 môi trường: Dev / Staging / Production Staging phải mirror production trước khi go-live
  • Pipeline CI/CD, quản lý secret, backup DB + media định kỳ
  • Monitoring lỗi publish / API / media

BaselineAudit & khoá scope

  • Crawl toàn site: lập danh sách 297 URL 404, tình trạng noindex/canonical
  • Quyết định domain chính www vs non-www Đầu vào cho redirect 301 ở P4
  • Lock scope IR: Stock, Disclosures, GMS + hành vi CMS
P1

IR Page Phase 2 — Stock & Disclosure

25/06 – 31/07/2026

DevTrang Cổ phiếu (Stock)

  • Tích hợp API Vietstock lấy dữ liệu cổ phiếu real-time Có cache + fallback khi API lỗi; không vỡ trang
  • Build UI theo Figma sẵn có; update text

DevTrang Công bố thông tin

  • Build trang Disclosure từ Figma
  • Bổ sung CMS module upload tài liệu cho Disclosure Phân loại, thay file giữ URL, phân quyền

OpsVận hành & đo lường

  • Viết tài liệu vận hành IR page (CMS, quy trình)
  • Cài tracking cơ bản cho IR: view, click, download, outbound
P2

Nền tảng CMS — trọng tâm dự án (Admin Autonomy)

31/07 – 20/09/2026

CoreNội dung & Xuất bản

  • WYSIWYG / block builder + autosave + preview sát bản publish
  • Workflow trạng thái Draft → Review → Approved → Published → Archived
  • Version history + so sánh + rollback không mất lịch sử
  • Schedule publish/unpublish; cảnh báo rời trang chưa lưu

AssetsMedia & Banner

  • Media library tập trung: folder/tag, thay file giữ URL, alt/caption
  • Tối ưu ảnh (WebP), validate MIME, scan malware, chặn file thực thi
  • Quản lý banner desktop/mobile: CTA, thứ tự, lịch, tự ẩn khi hết hạn

GovernancePhân quyền & Audit

  • RBAC 5 vai trò: Master Admin, Admin, Editor, Contributor, Viewer Least privilege, session timeout, kiến trúc sẵn multi-site 2027
  • Workflow duyệt: separation of duties, comment, thông báo
  • System log bất biến + filter + export; soft delete / trash

DiscoverabilitySEO, Menu, Đa ngữ

  • Trường SEO per-page: title, meta, slug, OG, canonical, schema
  • Auto sitemap.xml khi publish + trình quản lý redirect 301
  • Quản lý menu header/footer kéo-thả đa cấp, cảnh báo link gãy
  • Song ngữ VI/EN độc lập + liên kết bản dịch + fallback

PlatformAPI, Bảo mật & Vận hành

  • API có auth + rate limit cho frontend tiêu thụ dữ liệu
  • SSO/MFA, chống XSS/CSRF/Injection, khoá tài khoản khi login sai
  • Webhook clear cache/trigger build; tích hợp CDN, GA4/GTM, email
  • Tách rời: CMS lỗi không làm sập website public

UX AdminDashboard & Form

  • Dashboard theo đầu việc: chờ duyệt / sắp publish / vừa cập nhật
  • Search / filter / bulk actions cho người không chuyên kỹ thuật
  • Form builder (Contact/Newsletter/IR): consent, CAPTCHA, export Conditional

P4

SEO kỹ thuật & AIO Readiness

Build → UAT

FoundationDọn nền SEO

  • Gỡ x-robots-tag: noindex sai; chuẩn hoá robots.txt
  • Redirect 301 chuẩn hoá www/non-www
  • Map 297 URL 404 → trang đích mới

BuildStructured data (JSON-LD)

  • Organization schema (homepage) + Breadcrumb động theo URL
  • FAQPage, NewsArticle/Report, Person (leadership) schema
  • Hreflang + lang=vi/en cho từng bản dịch

AIOCấu trúc cho AI/LLM

  • Topic cluster routing (hub/node) thay cấu trúc phòng ban cũ
  • XML sitemap tự sinh, chỉ chứa canonical hợp lệ
  • Nội dung facts dạng máy đọc được cho trang Tác động

⚠ Rủi ro & mâu thuẫn timeline

  • Mốc Dev lệch: web-mng đòi xong Dev 10/08 nhưng web-tracking kéo đến 20/09. Chốt theo 20/09 vì phụ thuộc Figma 15/07.
  • Security 25/08 bất khả thi nếu code kéo đến 20/09 → chuyển sang kiểm thử song song 25/08–10/09 hoặc ngay sau code.
  • Figma là đường găng: Dev frontend không thể bắt đúng hạn nếu Figma chưa approved 15/07.
  • Auto-pull IR → Tin tức: phụ thuộc IR Phase 2 xong trước; cần tránh trùng nội dung.
  • Dependency nội dung/URL từ CC/BIE chặn hầu hết hạng mục SEO/AIO.

✓ Nguyên tắc ưu tiên khi build

  • Foundation trước: môi trường, CI/CD, redirect/canonical, robots — làm sớm để không cản launch.
  • CMS là xương sống: ưu tiên các module Must-have còn "Chưa có" (media, workflow, version, RBAC, audit, SEO, menu).
  • Embed ≠ rebuild: BU, Career, IR, DMF/UpRace chỉ nhúng/link — tiết kiệm effort lớn.
  • Tách rời public/CMS để giảm rủi ro vận hành.
  • Kiến trúc linh hoạt multi-site ngay từ đầu, tránh làm lại nền năm 2027.
